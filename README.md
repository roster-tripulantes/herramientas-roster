# Herramientas equipo Roster

Portal de herramientas del equipo de programación de tripulantes.

Abrir: https://roster-tripulantes.github.io/herramientas-roster/

El acceso requiere la clave del equipo. El contenido está cifrado y las herramientas procesan los archivos solo en el navegador de cada persona: no se envían ni se guardan datos en ningún servidor.
